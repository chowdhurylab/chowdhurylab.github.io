The accepted count matches the latest certified local checkpoint. The complete
public export also includes later, nonaccepted records. This release does not
constitute a new scientific audit of those records.

The existing table layout, public download fields, and on-demand record
details are retained. Search suggestions now open above low-positioned fields
when needed and stay within the viewport.

Review labels use plain text, without repeated colored dots or distribution
bars. Expanded counts separate six recorded outcomes instead of grouping
unverified, calculated, and disputed records together. Full-download sequence
and SMILES coverage is explicitly separate from filtered review counts.
Coverage gaps are not presented as reasons for pending checks or as evidence
of review speed. The Guide no longer makes a blanket lab-member review claim.
Private review notes and internal reasoning are not added to the public
interface or download schema.

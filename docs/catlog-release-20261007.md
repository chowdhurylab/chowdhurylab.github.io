# CatLog Snapshot: October 7, 2026

This release contains 159,446 records, including 16,966 accepted records
(8,914 Verified and 8,052 Corrected). The October 2 release contained 158,795
records and 16,249 saved accepted statuses.

The snapshot was built from the current certified checkpoint. The catalog
file and certification remained unchanged through the build; the recorded
apply, integrity audit and exact readback support that checkpoint. Exporting
the website does not perform additional scientific review.

Source SHA-256:
`4434a604ae0387577544b5c1f59d03399a3bce26d713d70479ee61abddb20553`.
Exporter commit: `23417e3f60092e635caddeed09e13a83c3c1cf6b`.
Certified checkpoint: `d241dad83bc1348b37cdee33edd44fe13679c658`.

The full public download includes protein sequences, wild-type and variant
sequences, substrate SMILES, references and source information where available.
Internal model reasoning and raw backend records are outside the public data.
Browse, Guide and Stats retain their existing layout. The Guide now describes
paper excerpts as saved text, without implying that every excerpt states the
exact value and unit.

The operator approved retirement of the exact 638 superseded September 23
public files (90,476,637 bytes), bound to public commit
`1ba6f5cd64d7d26ec2bfb3029da1855cb6f03a03`. October 2 remains the compatibility
predecessor. Legacy compatibility files, human-review records, backend data
and Git history are preserved. September 23 immutable download paths are
retired; their content remains recoverable through Git history.

The stable entry points remain `/tools/catlog-latest.html` and
`/tools/catlog-stats.html`.

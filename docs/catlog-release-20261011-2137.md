# CatLog release October 11, 2026

- Records: 168,611, of them 44,915 accepted (Verified and Corrected). Data ID f450cca254.
- New from CatLog: CatLog read 1,163 papers; 1,149 of them give 30,541 records and 14 give none.
  Each value was read from the paper by an AI model and checked against the paper by a second, separate AI run;
  code converted the units. These records replace the papers' 21,376 older records (2,592 of them accepted); papers that give none no longer show older records.
- Older records: the October 7, 2026 catalog (data generation d241dad83bc1).
- Site changes in this release: Remove unused styles and code from the CatLog page (the stylesheet is 10 KB smaller); Faster loading: the first page of records appears while the rest downloads, Stats and Guide no longer download the records, and a record opens at once after pointing at its row; Remove two unused pieces of the CatLog page script (an old evidence-group list and its row lookup); Page 1 no longer jumps up while records load on tablet-width screens, and passing the pointer over Browse on the Stats page no longer downloads the records; The Stats page build now stops with an error when one of its page edits does not apply exactly once, instead of shipping a Stats page that first shows Browse; Search matches every word in any order and knows common species names (human, mouse, yeast, E. coli); an EC number in the search or the EC filter matches whole parts, so 1.1.1 no longer returns 3.1.1.1 or 1.11.1.x; Status column shows one left-aligned badge (a coloured dot, the status word, then whole-word tags such as human-checked that never break), every table row is the same height, value markers sit beside the value, names wrap to two lines with the full name on hover, a record open hides EC, temperature and pH instead of Status, the header keeps the tabs on one line on tablets, no-match searches explain themselves with a button back to all records, and keyboard users get a skip link, visible focus and labelled filters; Record panel is shorter and clearer: one status line (for example "Accepted · read from the paper · human-checked"), a CatLog v2 record's conditions as short labelled lines (Cosubstrate, Conditions as a list, Preparation), plain short sequence notes, the evidence label beside the paper links, ×10ⁿ values at full size, and "License: CC BY 4.0 (CatLog)" for values CatLog read from papers; On screens from about 1010 to 1400 px wide every table column fits again, Status included, with tighter cells and room for enzyme names in two lines; narrower screens scroll the table sideways with the enzyme name kept in view; Design notes describe the table sizing on tablets, the evidence label beside an older record's paper links, and the short sequence notes; On phones and tablets the "No records match" notice stays on screen instead of sitting off to the right of the wide table; Easier to read: one type scale and one set of colours on every page (no text below 11 px), the counts on one line, table columns sized to their content so the values sit next to the names, temperature and pH in one Assay column, very large and very small numbers written as a × 10ⁿ, and records shown as cards on phones; Record panel without repeats (no second SMILES label, no Databases or Database rows line that only repeats the source), the Stats chart says where the outer ring is not split by field, and on phones a no-match note sits under the toolbar instead of over it; Table columns fit the page better: values, EC, Assay and Status are as wide as their widest entry and never wrap, name columns are as wide as most of their names, so the values sit right after the names; filter checkboxes are closer together and the Stats subheadings share one size; On phones the open record's name is 18 px and loading placeholders line up with the cards; the record panel's protein section heading sits as close to its lines as the other sections; Name columns are capped a little narrower (Organism 200 px, Substrate 220 px) and widen into spare room only as far as a long name needs to fit in two lines, so the values stay close to the names on more pages; Long names are no longer cut short while the table has room: a name column widens until each name fits in two lines, and the space still left over stays at the right edge; New Guide, the PNAS Nexus citation and plainer wording: one readable Guide column with three plain steps, where the values come from, what to check before using them, downloads, how to cite and source licences (CatLog's own compilation is CC BY 4.0); "Pre-review" is now "Not reviewed" and records without a PMID or DOI say "no paper linked"; the record panel shows the values as the paper prints them and a "Report a problem" link; Smaller stylesheet: the older Guide rules that the new Guide layout fully overrides are removed and the Guide rules are written one per line like the rest, so the page looks the same and the stylesheet is back under 64 KB.
- Human review: 1,981 records had every value approved by a human reviewer; the 1,798 accepted ones show "human-checked".

# CatLog release October 12, 2026

- Records: 168,765, of them 46,829 accepted (Verified and Corrected). Data ID 14ffa6600b.
- New from CatLog: CatLog read 1,313 papers; 1,297 of them give 33,752 records and 16 give none.
  Each value was read from the paper by an AI model and checked against the paper by a second, separate AI run;
  code converted the units. These records replace the papers' 24,433 older records (3,889 of them accepted); papers that give none no longer show older records.
- Older records: the October 7, 2026 catalog (data generation d241dad83bc1).
- Site changes in this release: Stats can now count papers, human-checked records, EC classes, common organisms and EC numbers, enzyme forms, conditions, cautions, value ranges and main sources from the Full data download of the same snapshot; Stats is one plain page of bars with exact counts that link into Browse: review status, records read from the paper (CatLog v2), human-checked records, what the records contain, enzyme classes, the most common organisms and EC numbers, value ranges, wild type and variants, cautions and main source; the two-ring chart is gone; Human-checked records are easy to spot: a small green check marks the human-checked tag in the table, on phone cards and in the record's status line, the record has its own Human review line with the reviewer's note, and the counts band shows Human-checked N as a link to those records; odd records read plainly in the record panel (long names set smaller, "EC unknown" or "organism unknown", a note when no kcat, Km or kcat/Km is stored, "None recorded" for a missing sequence or SMILES, and a paper without a PMID is never linked to PubMed); The Guide is reorganised for visitors: a short introduction, an On this page list, then Find records (with example links to filtered views), Read a record (with the cautions and what each means), Review status (each status and tag, including human-checked), Units, Downloads, Before you use the values, Cite, Sources and licenses, and Questions; each section has its own address (#guide-units); On phones the Human-checked count in the counts band is easier to tap; The Guide's answer on missing sequences says that a variant without placed mutations shows the wild-type reference; Browse keeps its search, filters, sort, rows per page and page in the address (#browse?...), so a copied link opens the same records, and Back and Forward restore them; Filters gain Human-checked, Wild type or variant, temperature and pH ranges, Cautions and Main source, each with its count; Has kcat, Has Km and Has kcat/Km together show records with all of them; Each active filter and the search show as a removable chip above the table, with Clear all; From 1280px wide the filters open as a column beside the table and the results follow each change, from 1600px they stay open beside a record, and every filters overlay ends with Show N records; Search and the name filters match regardless of case, accents, Greek letters or their names, µ/micro/u, dashes, primes, and hyphens or spaces inside a name (4 nitrophenyl = 4-nitrophenyl); the organism filter knows E. coli and human; EC numbers can be typed as EC 1.1.1.1, ec:1.1.1.1 or 1.1.1.-, a class as 1. or EC 1, and several in the EC field; When no record matches, the table names the filters that are on and offers to remove the one set last, with how many records that would show, or to clear them all; Rows per page is remembered in this browser, a sort chosen from a column header is announced to screen readers, and a single result reads 1 record; The browser checks open filtered addresses, the Human-checked filter and a pH range, and the design notes describe the filter panel, chips, address and search matching; The filter counts are worked out when the panel opens or in an idle moment, so they never delay the first full table; EC typed alone in the EC field filters nothing until a number follows; When no record matches, the filter offered for removal is the one set last that brings records back; Filter links also accept lists written with | (variant=wild|variant), and the browser checks expect the address left after Clear all; The browser checks expect Browse to keep the filters a Stats link set after Back, and Clear all to show every record again; The Human-checked count links to the filters set now, from the first page, also while a record is open; it is plain text when it is 0, shows a dash on a filtered view until the review marks arrive, and uses the snapshot count only when it belongs to this snapshot; Stats counts each organism and source as its Browse link finds them (strains with their species, a record merged from several databases under each), so every linked count equals the records it opens and the Guide's source counts; source and caution names match the filters; An open record keeps the filters in the address (#browse?...&record=), so reloading, a copied link and Esc keep them and the record opens on its page; review marks that arrive later update the open record in place; The browser checks open a record under the Human-checked filter, reload it and close it, and expect the filters to stay in the address; Filters open as a column beside the table from 1440px (an overlay below that, so 1280px laptops keep readable enzyme names); beside them names never break inside a word, a table still too wide shows the Columns control and keeps Enzyme in view, and closing a record brings the filters back where they were; A calculated kcat/Km shows in the table with the significant figures of its kcat and Km, as in the record, and the Guide's Units section says plainly that stored values drop trailing zeros and round long values; Stats says that value ranges leave out values in other units, gives the 10–90% bounds to two significant figures, and notes that Human-checked also uses the review marks; In the Organism field a common name matches as a whole word, so rat finds rats (6,059 records) and no longer Serratia or the golden hamster; Human review notes no longer show a review year; the Guide's record example matches the record (8.2 × 10⁻⁴ mM, human-checked), its cautions say which ones carry the amber mark and how the Cautions filter groups them, and the kcat/Km example view lists accepted records; Stats stacks its last four sections in two columns with no blank gap, the phone Accepted column fits its heading, and on tablets the counts band takes two tidy lines without a stray divider; A link sorted by a value waits for every record before it shows rows, saying it will sort when loading is done, instead of showing a top 25 that then changes; The browser checks follow the top organism and BRENDA links from Stats and expect Browse to show the counts Stats gives; The Main source note says the source counts can add up to more than all records.

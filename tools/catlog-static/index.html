CatLog in numbers

Using CatLog

CatLog lists enzyme kinetic constants (kcat, Km, kcat/Km), each with its enzyme, organism, substrate, assay conditions and source paper. It is maintained by the Chowdhury Lab at Iowa State University.

The CatRange paper (PNAS Nexus, 2026) describes CatLog-27k, 27,176 kinetic records curated from BRENDA and SABIO-RK on which its models were trained; this site is the growing catalog that followed. How its values are read and checked now is described below, under Where the values come from.

How to use CatLog

Search and filter

Type an enzyme, EC number, organism, substrate, UniProt accession, PMID or DOI: laccase, 1.10.3.2, P11509, 12514023. Several words narrow the search (Trametes laccase); common names such as human, mouse, yeast or E. coli find the species, and β-lactamase finds beta-lactamase. Gene names are not indexed.

Filters combine review status, EC number, enzyme, organism, substrate and measurement type (kcat, Km or kcat/Km); in Filters, EC 1.1.1 lists the whole subclass. The table sorts by status, EC number, name or value, ascending or descending.

Open a row

The record gives the values and units, assay conditions, protein sequence, substrate SMILES and paper, and the address bar then holds a link to that record, to share or bookmark. On a from-paper row, Review notes show each value as printed in the paper, as stored, and what the second check found. Report a problem e-mails the lab about the record.

Download

Full data has every row, with sequences and SMILES where known. Download page saves the rows on screen; Download record saves the open record.

Where the values come from

Rows marked from paper are CatLog v2: an AI model (Claude, Anthropic) read each value from the paper, a second, separate AI run checked it against the paper, and code converted the units. Older rows come mostly from enzyme databases and were checked by an earlier automated pipeline of AI models and code checks.

An accepted record is marked human-checked when a human reviewer approved every value it shows; most records have not been checked by a person. Papers are being re-read, and a re-read paper’s from-paper rows replace its older rows.

Field meanings

kcat
Turnover number, s-1.
Km
Michaelis constant, mM.
kcat/Km
Catalytic efficiency, s-1 mM-1 (multiply by 1,000 for M-1 s-1). calc. marks a kcat ÷ Km worked out from the two values, not printed in the source.
T (°C)
Assay temperature.
pH
Assay pH. The record lists the other conditions.
Unknown
Not stated in the paper or the source database.

A dash means a value is missing or hidden after a data check. Open the row to see why.

A warning marks a value to check against its source. Open the row for the reason.

no unit: the source gives no unit, so the column unit does not apply.

Numbers of 100,000 or more and below 0.001 are written as a × 10n (8.2 × 10-4), with the same digits.

Review status

Each record has one status, set by CatLog’s checks.

Accepted
As reported, or after a correction (tagged corrected).
Acceptedfrom paper
A CatLog v2 row, read from the paper and checked against it (see Where the values come from). The filter Read from the paper (CatLog v2) lists only these.
Acceptedhuman-checked
A human reviewer approved every value the record shows (on a from-paper row, the same values in the earlier catalog).
Acceptedno paper linked
No PMID or DOI is linked, so the value cannot be checked against a paper.
Checks pending
At least one check is still open, for example on the value, protein or substrate.
Unverified
No accepted result is recorded.
Not reviewed
Prepared from source records, without an accepted review.
Disputed
Flagged during review; not accepted.
Evidence labels on older records
Paper excerpt
Saved paper text; it may describe context rather than this value. An excerpt alone does not mean Accepted.
Database note
A database note is saved; no paper-value excerpt is attached.
Several database records
The record merges several database entries; no paper text is saved.
Paper linked
A PMID or DOI is linked; no paper text is saved.
Database record only
Only the source database record is saved.

Before you use the values

Units
A few older rows keep another unit, shown after the value (min-1, mg/mL), or have no unit; those numbers are not in the column unit.
kcat/Km
A printed kcat/Km that differs from kcat ÷ Km is kept and flagged. The record gives both numbers, how far apart they are and, for a familiar factor such as 1000, the likely cause.
Sequences
A variant’s sequence includes its mutations only where CatLog could build it; otherwise the record gives the wild-type reference.
Merged rows
Some older records merge several database rows; the record says how many and lists their papers.

Downloads

Every row and field, including sequences, SMILES, PMID and DOI.

Review files
